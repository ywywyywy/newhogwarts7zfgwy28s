# HOGWARTS — домашняя видеотека

Мобильный HTML-сайт в тёмно-фиолетовом стиле с золотыми деталями. Нижнее меню: Меню, Сериалы, Расписание, Настройки. В расписании указаны уроки с понедельника по пятницу и правила начисления баллов.

## Публикация
1. Создай публичный репозиторий на GitHub.
2. Загрузи `index.html`, `media.json`, папки `images` и `videos` в корень репозитория.
3. Открой Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Сайт появится по адресу вида `https://ТВОЙ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Как добавить серию (плеер уже работает)
1. Положи MP4 в папку `videos` (например `videos/episode5.mp4`).
2. Добавь строку в `media.json`: `{ "title": "Серия 5", "file": "videos/episode5.mp4" }`.
3. Если видео на YouTube (доступ по ссылке): `{ "title": "Серия 5", "youtube": "ID_ВИДЕО" }`.
4. Серия появится в списке сама. Локально сайт нужно открывать через сервер; на GitHub Pages всё работает сразу.

Размер: через веб-интерфейс GitHub файл до 25 МБ, через git — до 100 МБ; весь сайт желательно до 1 ГБ. Видео лучше сжать (H.264, 720p, например в HandBrake).

## Старая заметка
Загрузи видео MP4 в `videos`, обложку в `images`, затем мы обновим страницу сезона, чтобы показывать серию с плеером. GitHub Pages — статический хостинг: файлы добавляются через репозиторий, а не через загрузку на сайте. Для больших видео лучше использовать внешнее видеохранилище.


Интерфейс дополнительно отполирован: улучшены зоны нажатия, адаптивность, состояния кнопок и подсветка текущего учебного дня. На главном экране есть раскрывающийся справочник «Полезная информация»: дисциплины, оценки, курсы, факультеты и ссылка на дополнительные материалы.
